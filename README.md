# MyFinances V10.37 — исправления интерфейса и категорий

## Что изменено в V10.37

- Исправлено поведение нажатий: вся карточка операции в последних операциях и истории открывает соответствующую запись; в списке категорий короткое нажатие открывает историю этой категории в текущей кассе, а удержание открывает новую операцию с уже выбранными категорией и кассой.
- История категории показывает операции только выбранной категории и текущей кассы, группирует их по датам, поддерживает сортировку по дате/сумме и поиск по конкретной дате с контекстом до пяти записей до и после.
- В форме операций сохранены семь избранных категорий и кнопка замены, калькулятор, быстрые даты и календарь, текстовые теги и голосовой ввод. Выбранная категория получила более заметную мятную обводку и согласованные размеры.
- Поля периода получили отдельные равномерные рамки; стрелки периода перенесены над кнопками добавления и голосового ввода; длинные суммы используют свободное пространство перед переносом знака рубля.
- Счёт в форме операции оформлен компактнее, как переключатель на главном экране. Настройки цветов категорий используют восемь предустановленных цветов и отдельный выбор произвольного цвета.
- Убраны создание новых переводов и связанные с ними элементы интерфейса. Старые записи переводов не удаляются из хранилища и не пересчитываются автоматически; они доступны только как архивные записи.
- Добавлены общие правила против выделения обычного текста и автоматического фокусного масштабирования Safari. Исключение для выделения текста — только поле «Описание» операции. Исправлены правила ширины для предотвращения горизонтального переполнения и лишнего текста `\n`.
- Подправлены иконки приложения, выровнены их границы, исправлено масштабирование миниатюр. Устаревшее сообщение о переводах удалено из аналитики.
- Сохранён ключ финансовых данных `my-finances-v1`; существующие счета, категории и операции не сбрасываются.

## Проверки и ограничения

- Проверены синтаксис JavaScript, структура HTML, наличие согласованных элементов формы, отсутствие кнопки создания переводов, восемь цветов палитры и версия Service Worker.
- Запуск в реальном Safari на iPhone в этой среде недоступен. После публикации проверь автоматическое масштабирование полей, микрофон, календарь и открытие карточек на устройстве.

## Установка

1. Сначала сохрани резервную копию через «Настройки» → «Резервная копия и перенос».
2. Распакуй ZIP и загрузи **содержимое** папки `my-finances-v10.37-redesign` в корень существующего репозитория GitHub Pages, заменив соответствующие файлы.
3. Сделай commit и дождись публикации. Полностью закрой MyFinances и открой заново, чтобы обновился Service Worker.
4. Проверь добавление расхода и дохода, замену избранной категории, календарь, калькулятор, теги, выбор счёта и историю.

## Что изменено в V10.34

- Добавлены разговорные формы чисел «тыща», «тыщи», «тыщу» и близкие варианты. Например, «тыща 500 руб.» разбирается как 1 500 ₽ без остатка слова «тыща» в описании.

- Сохранён ключ финансовых данных `my-finances-v1`, пользовательские счета, категории и операции. Сброса данных и миграции нет.
- Не используются платные API или внешние платные сервисы.

# Мои финансы — V10.33 — исправления диктовки и подтверждение перед сохранением

## Что изменено в V10.33

- Голосовая операция из буфера обмена по умолчанию открывает форму проверки. Она ещё не сохраняется, пока пользователь не нажмёт «Сохранить».
- В «Настройки» → «Голосовой ввод» можно выбрать режим «С подтверждением» или «Сразу сохранять». Настройка хранится отдельно от финансовых данных.
- Сохранён существующий встроенный микрофон: он по-прежнему заполняет форму, показывает распознанные поля и требует ручного нажатия «Сохранить».
- Название счёта удаляется из текста до поиска категории, чтобы, например, «Личная касса» не совпадала случайно с категорией «Личный».
- Тип операции больше не выбирается по случайно найденной категории. При отсутствии явного признака дохода используется расход; узнаваемые слова о доходе (например «зарплата», «получил») по-прежнему распознаются как доход.
- Добавлены семантические подсказки для ряда покупок (например, «мороженое» и «шаурма») для подбора категории «Продукты», если такая категория есть. Название покупки остаётся в описании.
- Последние операции при одинаковой дате сортируются с учётом порядка добавления, чтобы новая запись не терялась ниже старых записей за тот же день.
- Возвращение из «Команд» в установленное PWA дополнительно отслеживается событиями `pagehide`/`pageshow`, чтобы сделать подсветку кнопки вставки устойчивее на iOS.
- Обновлён ключ кэша Service Worker, чтобы браузер мог запросить файлы новой версии.
- Финансовый ключ хранения `my-finances-v1`, существующие счета, категории, операции, фильтры и резервные копии не сбрасываются и не мигрируют.
- Не используются платные API и внешние платные сервисы.

## Перед обновлением

5. Сначала проверь голосовой ввод с режимом «С подтверждением» на тестовой операции. Не подтверждай её, пока не проверишь счёт, тип, сумму, категорию и описание.

## Что изменено

- Импорт JSON показывает предварительную сводку: период, количество счетов, категорий и операций, суммы доходов/расходов/переводов, пропуски счетов и категорий.
- Перед импортом автоматически скачивается резервная копия текущих данных. Импорт отменяется без изменений, если формат не прошёл проверку.
- Необычно крупные операции (свыше 1 000 000 ₽) отмечаются отдельным предупреждением и требуют дополнительного подтверждения.
- В голосовой ввод добавлена нормализация нескольких частых вариантов распознавания слова «трайфл» и английского `trifle`. Это исправляет известные варианты, но не может гарантировать восстановление слова, если браузер вообще не передал похожий вариант распознавания.

- Голосовой ввод принимает сумму, описание, категорию, тип операции, кассу и дату в произвольном порядке.
- Распознаются суммы цифрами и словами на русском языке, включая форматы вроде «две с половиной тысячи», «полторы тысячи», «десять тысяч пятьсот пятьдесят рублей».
- Категория ищется не только в начале фразы; добавлены разговорные синонимы и варианты склонения.
- Если в фразе названа касса, она выбирается автоматически. «Вчера» и «позавчера» меняют дату операции.
- Если категорию нельзя определить уверенно, поле остаётся без выбранной категории — её можно указать вручную.
- Экран добавления операции получил более заметное поле суммы, более чёткие поля и отдельное оформление состояния микрофона.
- На главном экране отображаются только категории, по которым были операции в выбранном периоде и текущей кассе. Если операций нет, показывается спокойное пустое состояние; список категорий не захламляет экран. Категории можно создавать и настраивать в разделе настроек.
- Сохранены переключение касс, выбор периода, стрелки перехода по датам и быстрые кнопки добавления. При создании операции поле кассы сразу выбирает текущую кассу; её можно изменить прямо в форме до сохранения.
- Тема Emerald Glass: графитовый фон, глубокие зелёные поверхности и аккуратные изумрудные акценты.
- Фото к операциям не добавлялись. Платные API и внешние платные сервисы для парсинга не используются.
- Сохранены экспорт/импорт JSON, история, аналитика, категории, подкатегории и переводы между кассами.

## iPhone: диктовка через буфер обмена (v10.28)

В iOS схема `webapp://` может открыть установленное PWA, но не передать ему query-параметры. Надёжный обходной путь без платных сервисов: в Командах после «Диктовать текст» добавь действие «Скопировать в буфер обмена», затем открывай точный адрес установленного приложения через `webapp://` с завершающим `/` (без `?voiceText=...`). В открывшемся приложении нажми плавающую кнопку «Вставить диктовку». Приложение прочитает фразу из буфера и сохранит расход автоматически, если сумма распознана. Если сумма не распознана, откроется форма проверки.

Важно: на iOS чтение буфера обмена может потребовать подтверждения/разрешения; поэтому полностью без касания экрана этот вариант не гарантируется.
