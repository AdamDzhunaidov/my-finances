# Мои финансы — обновление v10.5

## Что обновлено
- Исправлены отображение и насыщенность значков категорий.
- В последних операциях рядом с датой отображается категория.
- Добавлен выбор одного из пяти вариантов значка в настройках.
- Убраны лишние манифесты: для приложения используется один `manifest.json`. Голосовой ввод не зависит от количества манифестов.
- Исправлены ссылки на иконки: архив содержит PNG 512×512, и код теперь ссылается на существующие файлы.
- Обновлён кэш service worker, чтобы браузер получил новую версию.
- Сохранён ключ финансовых данных `my-finances-v1` и существующая интеграция голосового ввода через `voiceText`.
- Не добавлены платные API или внешние платные сервисы.

## Важно про значок на iPhone
Выбор в настройках сохраняется и меняет `apple-touch-icon`, который сайт предлагает при добавлении на экран «Домой». iOS не позволяет веб-приложению гарантированно менять значок уже установленного ярлыка автоматически. Не удаляй установленный ярлык ради смены значка, пока не экспортировал резервную копию данных.

## Как обновить GitHub Pages
1. В текущем приложении открой **Настройки → Сохранить копию** и сохрани JSON-файл в «Файлы». Это страховка данных.
2. Распакуй архив. Открой папку `my-finances-v10.5`.
3. Загрузи **содержимое этой папки** в корень репозитория `my-finances`, заменив старые файлы. В корне должны лежать `index.html`, `manifest.json`, `sw.js` и папка `icons`.
4. Удали из корня старые `manifest-money.json`, `manifest-bank.json`, `manifest-wallet.json`, `manifest-coins.json`, `manifest-chart.json`, если они там остались. Они больше не нужны.
5. Дождись публикации GitHub Pages, полностью закрой приложение и открой его снова. Если видишь старую версию, открой сайт в Safari и обнови страницу.
6. Проверь голосовой ввод и последние операции. Данные должны сохраниться, потому что ключ локального хранилища не менялся. Всё равно сначала сделай резервную копию.

## Голосовой ввод
Существующая логика кнопки микрофона и параметра `voiceText` сохранена. Настраивать заново Команды iOS не требуется, если текущая команда уже работала.
