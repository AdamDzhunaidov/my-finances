# Мои финансы — версия 1.0

Бесплатный трекер доходов, расходов и переводов. Работает в браузере и может быть опубликован через GitHub Pages. Интерфейс на русском языке, адаптирован для iPhone.

## Возможности
- Доходы, расходы и переводы между своими счетами.
- Переводы меняют балансы счетов, но не входят в суммы доходов и расходов.
- Счета с начальным балансом.
- Категории и необязательные подкатегории; можно сохранять операцию без подкатегории или категории.
- Произвольная дата операции, описание, редактирование и удаление.
- История с поиском и фильтрами по типу и дате.
- Аналитика за выбранный месяц: доходы, расходы, разница, категории и подкатегории.
- Экспорт и импорт JSON-резервной копии.
- Голосовой ввод использует только встроенную возможность браузера, если она доступна; платные API не используются. На iPhone/Safari функция может не поддерживаться, ручной ввод работает всегда.
- Локальное хранение данных без регистрации и банковских подключений.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий на GitHub, например `my-finances`.
2. Загрузите в корень репозитория файлы `index.html`, `manifest.json`, `sw.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Подождите, пока GitHub опубликует сайт. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/my-finances/`.
7. На iPhone откройте адрес в Safari → **Поделиться** → **На экран «Домой»**.

Названия пунктов GitHub могут немного отличаться в мобильной версии. Не загружайте в репозиторий свою резервную копию или реальные финансовые данные.

## Важно о данных
Записи хранятся локально в браузере на устройстве. Они не синхронизируются автоматически между устройствами и могут исчезнуть при очистке данных сайта. Регулярно используйте **Настройки → Экспорт** и храните JSON-копию в личном безопасном месте, не в публичном репозитории.

## Ограничения первой версии
- Валюта отображается в рублях (RUB).
- Голосовое распознавание зависит от браузера и устройства.
- Данные не защищены паролем и не шифруются приложением; используйте блокировку устройства и не вводите сведения, которые не хотите хранить локально.
