# MyFinances V10.50 — оформление фильтров истории

Основа: MyFinances V10.49. Изменён дизайн списка счетов в окне «Фильтры истории»: более выразительная типографика, собственный индикатор выбора, мягкая бирюзовая подсветка выбранных счетов, ровные отступы и аккуратные кнопки.

Для отдельных счетов используются существующие `account.icon` из данных приложения, чтобы оформление совпадало с уже используемыми иконками счетов. Для пункта «Все кассы» используется стандартный значок кошелька.

Сохранены остальные функции и иконки V10.49. Имя кэша Service Worker обновлено.

Перед установкой экспортируйте резервную копию данных. Распакуйте архив и загрузите его содержимое в корень репозитория GitHub Pages, заменив одноимённые файлы. Затем сделайте commit, дождитесь публикации и заново откройте приложение.

Проверены структура архива, функция формирования строк фильтра, номер версии и имя кэша. Приложение не запускалось в реальном браузере.
