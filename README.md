# Мои финансы — версия 2.0

Мобильный веб-трекер доходов, расходов и переводов между своими кассами.

## Публикация на GitHub Pages
1. В репозитории `my-finances` открой вкладку **Code**.
2. Замени файлы `index.html`, `manifest.json` и `sw.js` файлами из этого архива (корень репозитория, ветка `main`).
3. В `Settings → Pages` проверь источник публикации: `main` и `/(root)`.
4. После публикации открой сайт на iPhone и обнови страницу. Если установленное на экран «Домой» приложение не обновилось сразу, закрой его полностью и открой снова; сервис-воркер использует новый кэш `my-finances-v7-cache`.

## Данные и резервная копия
- Операции хранятся локально в браузере на этом устройстве.
- В разделе **Настройки → Резервная копия и перенос** можно сохранить JSON-файл.
- На другом устройстве выбери **Восстановить данные** и укажи этот файл.
- Восстановление заменяет текущие данные. Сначала сохрани отдельную копию, если она нужна.
- Формат хранения `my-finances-v1` сохранён для совместимости с данными предыдущих версий приложения.

## Возможности
- Отдельный остаток и последние операции выбранной кассы.
- Доходы, расходы и переводы между кассами.
- Периоды: день, неделя, месяц, год и произвольный диапазон.
- Категории с раскрываемыми подкатегориями и быстрым добавлением.
- История с поиском по описанию, категории, кассе и сумме.
- Аналитика по месяцу и выбранной кассе.
- Экспорт и восстановление резервной копии, текстовый отчёт для отправки.
- Голосовой ввод, если он поддерживается браузером; платные сервисы не используются.
