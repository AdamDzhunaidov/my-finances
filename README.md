# Мои финансы — v10.17 Emerald Platinum Controls

Обновление интерфейса и голосового ввода. Все данные приложения по-прежнему хранятся локально в браузере устройства.

## Что изменено

- Голосовой ввод принимает сумму, описание, категорию, тип операции, кассу и дату в произвольном порядке.
- Распознаются суммы цифрами и словами на русском языке, включая форматы вроде «две с половиной тысячи», «полторы тысячи», «десять тысяч пятьсот пятьдесят рублей».
- Категория ищется не только в начале фразы; добавлены разговорные синонимы и варианты склонения.
- Если в фразе названа касса, она выбирается автоматически. «Вчера» и «позавчера» меняют дату операции.
- Если категорию нельзя определить уверенно, поле остаётся без выбранной категории — её можно указать вручную.
- Экран добавления операции получил более заметное поле суммы, более чёткие поля и отдельное оформление состояния микрофона.
- На главном экране отображаются только категории, по которым были операции в выбранном периоде и текущей кассе. Если операций нет, показывается спокойное пустое состояние; список категорий не захламляет экран. Категории можно создавать и настраивать в разделе настроек.
- Сохранены переключение касс, выбор периода, стрелки перехода по датам и быстрые кнопки добавления. При создании операции поле кассы сразу выбирает текущую кассу; её можно изменить прямо в форме до сохранения.
- Тема Emerald Glass: графитовый фон, глубокие зелёные поверхности и аккуратные изумрудные акценты.
- Фото к операциям не добавлялись. Платные API и внешние платные сервисы для парсинга не используются.
- Сохранены экспорт/импорт JSON, история, аналитика, категории, подкатегории и переводы между кассами.

## Обновление на GitHub Pages с iPhone

1. Перед обновлением откройте приложение и сохраните резервную копию текущих данных в настройках.
2. Распакуйте архив на компьютере или в приложении, которое позволяет работать с ZIP.
3. Загрузите файлы и папку `icons` из каталога `my-finances-v10.17` в корень существующего репозитория GitHub Pages, заменив одноимённые файлы.
4. Сделайте commit изменений и дождитесь публикации GitHub Pages.
5. Откройте приложение, обновите страницу. Если установленная PWA продолжает показывать старую версию, полностью закройте её и откройте снова; новая версия Service Worker имеет отдельный cache key.
6. Проверьте добавление тестового расхода и удалите его после проверки.

## Проверки

- JavaScript извлечён из HTML и проверен `node --check`.
- JavaScript проверен на синтаксические ошибки. Перед постоянным использованием проверьте голосовой ввод на своём iPhone: качество распознавания зависит от браузера и системного сервиса речи.
- Реальное распознавание микрофона зависит от поддержки `SpeechRecognition`/`webkitSpeechRecognition` браузером, разрешения микрофона и соединения. Для iPhone проверьте на вашем Safari/PWA.


## v10.17 — выравнивание основных кнопок
- Кнопки «+» и голосового ввода имеют одинаковые размеры, радиус и зону нажатия.

- Обновлена версия кэша service worker для принудительного получения новых файлов.
