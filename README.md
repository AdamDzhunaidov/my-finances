# MyFinances V10.48 — обновлённая форма иконок приложения

V10.48 — обновление иконок приложения поверх V10.47. Оно сохраняет основное локальное хранилище `my-finances-v1` и совместимость с резервными копиями формата 1 и 2. Новые копии экспортируются с форматом 3.

## Основные изменения

- У новых операций записывается время создания (`createdAt`); история, последние операции и окно операций категории используют дату операции и время создания, когда оно известно. У старых записей неизвестное время не выдумывается.
- Добавлены умный порядок категорий и ручной порядок быстрого доступа. В ручном режиме пользователь управляет списком от одной до семи категорий. Умный режим показывает недавно использованные категории первыми.
- Быстрый доступ можно настраивать отдельно для каждой кассы; эта возможность по умолчанию выключена. Категории остаются едиными объектами, не дублируются между счетами. Расходы и доходы имеют отдельный порядок.
- В режиме ручного порядка новая категория, создаваемая из формы операции, может быть явно закреплена в быстром доступе, если есть место. Выбор существующей категории в форме не меняет список быстрого доступа автоматически.
- Переводы между счетами выключены по умолчанию. При включении появляется отдельное действие на главной; переводы изменяют балансы двух счетов и не учитываются как доход или расход.
- Создание операции из окна категории заранее выбирает нужные тип, категорию и кассу.
- В поле добавления тега на мобильных экранах используется шрифт от 16 px для предотвращения автоматического увеличения Safari. Выбранные теги выделяются контрастнее.
- Обработчики сохранения не должны сообщать об успехе, пока запись не подтверждена. Импорт валидирует структуру данных и сохраняет дополнительную копию перед заменой. Копия хранится в отдельной базе IndexedDB, чтобы не занимать место основной базы в `localStorage`.
- Сохранены настройки темы, фильтры истории, быстрые подсказки описания, бюджеты и регулярные операции из V10.45.

## Категории быстрого доступа

В **Настройки → Счета и категории → Категории и быстрый доступ** можно выбрать расход/доход, режим порядка, а при желании — индивидуальные настройки по кассе.

- **Умный** (по умолчанию): использованные категории поднимаются вверх после успешного сохранения операции.
- **Ручной**: выбранный состав и порядок не меняются автоматически.
- Быстрый доступ показывает не более семи категорий. Кнопка «Категория» в форме открывает выбор существующей категории или создание новой.

## Данные и ограничения

Финансовые данные хранятся локально в браузере и не синхронизируются автоматически между устройствами. Экспортируйте резервные копии в безопасное место и не размещайте реальные финансовые данные или JSON-копии в публичном GitHub-репозитории. Дополнительная копия перед импортом может быть скачана из настроек.

Регулярные операции обрабатываются при открытии/возвращении приложения; GitHub Pages не гарантирует фоновые задачи, когда приложение закрыто. Автоматическое создание записей — это учёт операций, а не фактическая оплата счетов. Голосовой ввод зависит от возможностей браузера и устройства.

## Установка через GitHub Pages

1. Скачайте и распакуйте ZIP.
2. Сначала экспортируйте резервную копию текущего приложения.
3. Загрузите содержимое архива в корень существующего репозитория GitHub Pages и замените одноимённые файлы.
4. Сделайте commit и дождитесь публикации.
5. Полностью закройте MyFinances на iPhone и откройте снова.

После обновления проверьте добавление/редактирование операции, сортировку категорий, добавление тегов, импорт/экспорт и перевод (если он включён).
