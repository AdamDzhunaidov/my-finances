# Мои финансы — обновление дизайна и категорий

## Что обновлено
- Более глубокая графитовая тёмная палитра с повышенным контрастом.
- Более насыщенные акцентные цвета при сохранении сдержанного финансового дизайна.
- Настройка существующих категорий: название, тип, подкатегории, иконка и цвет.
- Каталог из 100+ эмодзи-иконок, палитра готовых цветов и выбор собственного цвета.
- Изменение категории сохраняет её ID, поэтому связанные операции и аналитика продолжают относиться к этой категории.
- Обновлены значки категорий в выборе операции и истории.
- Добавлены manifest, иконки приложения и service worker для установки как PWA и кеширования файлов.

## Публикация на GitHub Pages
1. Сделайте резервную копию текущего репозитория и экспорт данных приложения.
2. Загрузите `index.html`, `manifest.json`, `sw.js` и папку `icons` в корень репозитория.
3. В GitHub откройте **Settings → Pages** и проверьте, что публикация настроена из нужной ветки и корневой папки.
4. После публикации откройте сайт и проверьте главную страницу, историю, аналитику, добавление операции и редактор категорий.
5. Если приложение уже было добавлено на экран «Домой», закройте его полностью и откройте заново. При необходимости обновите страницу в Safari.

## Важно о данных
Операции и категории хранятся локально в браузере на устройстве. Обновление не должно очищать `localStorage`; тем не менее перед заменой файлов рекомендуется экспортировать резервную копию через настройки приложения. Удаление категории по-прежнему отвязывает её от операций — для обычной смены иконки или цвета используйте **Настроить**.

## Проверка
Встроенный JavaScript проверен на синтаксические ошибки с помощью Node.js. Перед использованием на основном наборе данных рекомендуется проверить обновление на копии/резервной копии.
