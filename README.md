# MyFinances V10.48 — функции V10.46 и новые иконки

Эта сборка основана на архиве V10.46 `smart-categories-time-transfers` и сохраняет его `index.html` и логику приложения. Добавлены новые отдельные PNG-иконки кошелька, мешочка с ₽, банка и графика.

## Сохранённые возможности V10.46
- Время создания новых операций (`createdAt`) и сортировка с учётом времени, когда оно известно.
- Умный и ручной порядок категорий быстрого доступа.
- Возможность отдельных настроек быстрого доступа по счёту (по умолчанию выключена).
- Переводы между счетами (по умолчанию выключены).
- Создание операции из окна категории с заранее выбранными типом, категорией и счётом.
- Улучшения мобильного ввода тегов.
- Более безопасная валидация импорта и резервная копия перед заменой данных.
- Сохранённые функции V10.45: темы, фильтры истории, подсказки описания, бюджеты и регулярные операции.

## Иконки
Для каждого из четырёх значков включены размеры 180×180, 192×192 и 512×512 пикселей. Размер 108×108 не используется. `manifest.json` указывает размеры 192×192 и 512×512 для установки PWA; `index.html` использует `app-wallet-180.png` как `apple-touch-icon`.

## Установка
1. Сначала экспортируйте резервную копию данных из текущего приложения.
2. Распакуйте архив и загрузите **содержимое** в корень существующего репозитория GitHub Pages, заменив одноимённые файлы и папку `icons`.
3. Проверьте, что GitHub Pages публикует нужную ветку и корневую папку, затем сделайте commit.
4. Дождитесь завершения публикации. Полностью закройте приложение на iPhone и откройте сайт заново.
5. Проверьте создание расхода и дохода, быстрые категории, дату/время операции, теги, экспорт/импорт и перевод (если включён).

Данные хранятся локально в браузере. Перед обновлением обязательно экспортируйте резервную копию. GitHub Pages сам по себе не синхронизирует данные между устройствами.
